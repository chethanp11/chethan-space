Context is not a prompt trick. In enterprise systems, context is a governed supply chain.

## What context includes

- Business definitions
- Metrics and semantic models
- Source documents
- Policy constraints
- User role and permissions
- Workflow state
- Historical decisions

## Design pattern

Treat context as an explicit layer with quality checks, ownership, freshness metadata, and evaluation.

```ts
export type ContextPacket = {
  sources: string[];
  policyScope: string;
  freshness: 'current' | 'stale' | 'unknown';
  confidence: number;
};
```

## Why it compounds

Once context is modeled explicitly, multiple AI workflows can reuse it instead of rebuilding assumptions from scratch.
